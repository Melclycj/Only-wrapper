Round 5 gap-closure code fixes for Phase 10. Two operator-confirmed gaps from gate attempt 4 (10-VERIFICATION.md Addendum 3), both core-value-adjacent (real terminal fidelity), fixed in one plan because they touch DISJOINT files (no write conflict):

1. **GAP-10-J (S2 — gate-qualifying). Scrolling the session history flips the sidebar status.** Operator verbatim: "when i scrolling the session history up, the status changes from free to in progress to waiting for you." Root cause is already located: `src/renderer/SessionView.tsx` `viewportLines()` (lines ~395-404) samples the agent-state classifier frame from `term.buffer.active.getLine(b.viewportY + i)` — `viewportY` is the VISIBLE viewport top, which MOVES when the user scrolls into scrollback. So `classify()` re-reads OLD frames from history and the status flips. The per-tick `classify()` seam (`agent-tick.ts decideAgentTick`) and the `classify()` reducer (`agent-state.ts`) are CORRECT; only the sampling SOURCE is wrong. Fix: sample from the LIVE tail — `term.buffer.active.baseY` (the top line of the live region; `baseY === viewportY` only when scrolled to bottom, `viewportY < baseY` when scrolled up). Read lines `baseY + i` for `i in 0..rows`. This makes the classified status scroll-position-independent.

2. **GAP-10-K (S3 — terminal-fidelity). Chinese/CJK does not render in the terminal.** Encoding is NOT the fault — UTF-8 is correct end-to-end (node-pty forwards UTF-8; xterm.js decodes UTF-8; `@xterm/addon-unicode11` gives CJK the right 2-cell width). Two real causes: (a) LOCALE — `pty.spawn` in `src/main/pty-manager.ts` (~lines 323-333) sets `env: { ...process.env, TERM, COLORTERM }` with NO explicit `LANG`/`LC_ALL`/`LC_CTYPE`. A Finder-launched app inherits no UTF-8 locale → CLI tools fall back to C/POSIX (ASCII) and won't emit CJK. (b) FONT — `--font-mono: 'JetBrains Mono', monospace` (`src/renderer/tokens.css:69`) has no CJK glyphs, so Chinese falls through to imperfect system fallback. Fix: resolve a UTF-8 locale in the spawn env (honor an existing UTF-8 `LANG`, default only when absent, cross-platform-safe) + append a CJK-capable monospace fallback to the `--font-mono` stack (and the xterm `fontFamily`).

Scope is EXACTLY these two gaps. Do NOT touch any CLOSED gap (GAP-10-A..I). Do NOT plan the `npm run make` lowdb crash (a separate todo). Renderer + main only; the 20-key bridge surface (EXPECTED_API_KEYS) is frozen; no `data-testid`/class rename; renderer CSS uses only `var(--token)`.
