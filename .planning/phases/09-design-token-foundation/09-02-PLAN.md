<objective>
Migrate the globally-repeated raw primitives in `terminal.css` and `status-colors.ts`
from literals to `var(--token)` references (and `color-mix` for the alpha washes), and
add the static-text completeness guard that proves the single source of truth holds.

This is Wave 2 — it consumes the `tokens.css` layer and loaded fonts created by Plan 01.
It cashes in UI-01's "change one thing, change it everywhere" payoff: after this plan,
retuning the brand blue or the danger red is a one-line edit in `tokens.css`, not 28 + 8
hand-edits.

Per D-01 (hybrid scope): this plan migrates ONLY the cross-cutting global primitives —
the accent/danger colors, the 5 status accents, the 3 shadows, the font stacks, and the
motion. It does NOT migrate per-surface spacing VALUES (padding/gap/margin) — the
`--space-*` scale was DEFINED in Plan 01 for Phases 10–13 to consume, but existing
spacing literals are left untouched here.

Purpose: SC2 (all global colors/type/radius/shadow/motion sourced from named tokens) +
SC3 (single source of truth — re-theme in one place) for the global primitives.

Output: a value-preserving `terminal.css` consuming tokens, a migrated `status-colors.ts`,
the updated `status-colors.test.ts` guard, and the new `tokens-completeness.test.ts`.
</objective>
