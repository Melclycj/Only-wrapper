| renderer → no new IPC | This plan adds a build script + a docs file; no bridge surface changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Denial (functional) | font assets 404 under file:// in the packaged build | mitigate | `assert-fonts-bundled.cjs` asserts woff2 are emitted AND that the renderer CSS has no absolute `url(/` font path — locking in RESEARCH's relative-base finding and catching a future base-flip regression. |
| T-09-07 | Tampering | value-preserving regression slips past automated checks | mitigate | The end-of-phase human-verify eyeballs SC1 coherence, the ~4 hover-wash sites, and the full app against the "same look, new fonts" contract before the phase gate flips. |
| T-09-08 | Elevation | renderer bridge surface | accept | No IPC/bridge key added — EXPECTED_API_KEYS stays 20 (existing `security.guard.test.ts` GREEN). |

## Reliability & Cost Lens

| Failure mode | Component | Disposition | Note |

| Human-verify skipped / auto-approved | phase gate | mitigate | `human_verify_mode: end-of-phase`; the checkpoint is blocking-human — nyquist_compliant does not flip without the explicit approval. |
