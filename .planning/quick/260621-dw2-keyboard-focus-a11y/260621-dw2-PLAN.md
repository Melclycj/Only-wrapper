# Quick Task — Design Audit Wave 2: keyboard / focus a11y

Closes the audit's systemic weak pillar (Consistency & A11y 2.8/5): keyboard focus was
missing across rows, the terminal, and the modals.

## Scope — 6 fixes
1. **Shared focus-trap** — new `use-focus-trap.ts` hook (trap Tab + restore focus to opener),
   wired into all 4 modals (Confirm / SessionEdit / Preferences / RestartApply).
2. **Backdrop guard parity** — mousedown-origin check (only a true backdrop click dismisses)
   replicated from SessionEditModal into the other 3.
3. **Sidebar row focus ring** — `.sidebar-row:focus-visible` (+ `.add-session:focus-visible`).
4. **Terminal well focus** — `.terminal-well:focus-within` inset accent ring (geometry-safe).
5. **SearchBar disabled** — prev/next `disabled` at 0 matches + `.search-control:disabled`.
6. **cwd error aria** — `aria-invalid` + `aria-describedby` on the cwd input, `role="alert"`
   on the error notice (neutral hint stays non-assertive).

## Files
new `use-focus-trap.ts`; `ConfirmModal/PreferencesModal/RestartApplyPrompt/SessionEditModal/
SearchBar.tsx`; `sidebar.css / terminal-area.css / terminal.css`.
